# Hi, I'm Boumi

I'm the founder and solo developer of **[Classinus](https://classinus.com)**.

## What is Classinus?

**Classinus is an AI assistant and personal workspace.** It lets you talk to AI models, connect external services and MCP servers, and keep your files, notes and conversation history in one place.

- **AI assistant:** conversations, model selection and connected tools.
- **Personal workspace:** file library, notes, history and personalization.
- **Media:** previews for documents, images, audio, video and interactive content.
- **Connections:** integrations with external services and MCP servers.
- **Code and browser agents:** agents can run code and drive a real web browser inside sealed Docker boxes, with human approval for sensitive actions.
- **Bambara voice mode:** a spoken chat in Bambara.
- **Everywhere:** web, Android, iOS and Windows.

Website: **[classinus.com](https://classinus.com)**
